# ขอบเขตงานและข้อกำหนดการดำเนินงาน (TOR)

**โครงการ:** เว็บไซต์ทางการ Yangnar Studio

**ผู้ว่าจ้าง:** Yangnar Studio

**ระยะเวลาดำเนินงาน:** 1 เดือน
**ค่าบริการรวม:** 45,000 บาท

## 1. วัตถุประสงค์

จัดทำเว็บไซต์ทางการของ Yangnar Studio เพื่อแนะนำสตูดิโอ นำเสนอผลงาน แนวคิดการทำงาน กิจกรรมของ Pham / ผาม รางวัล และช่องทางรับ inquiry โดยทีม Yangnar Studio สามารถแก้ไขเนื้อหาหลักผ่าน CMS ได้หลังส่งมอบ

## 2. ขอบเขตงาน

เว็บไซต์เป็นภาษาอังกฤษและมีหน้าเว็บไซต์หลักแบบ single-page ประกอบด้วย:

1. Header และ navigation
2. Hero และข้อมูลแนะนำสตูดิโอ
3. Selected Works พร้อมตัวกรองประเภทผลงาน
4. Project detail สำหรับผลงานเริ่มต้นไม่เกิน 6 โครงการ
5. Philosophy, Practice, ทีมงาน และกระบวนการทำงาน
6. ส่วน Pham / ผาม สำหรับ workshop และ activities
7. Awards และ press references
8. Inquiry form พร้อม dropdown ช่วงงบประมาณ
9. Footer และข้อมูลติดต่อ

ใช้ภาพถ่ายจริงเป็นหลัก โดยรองรับเนื้อหาเริ่มต้นประมาณ 20 รายการ แบบแปลนหรือ drawings จะนำมาใช้เฉพาะไฟล์ที่ผู้ว่าจ้างอนุมัติให้เผยแพร่

คุณเต้งเป็นผู้อนุมัติทิศทางและงานออกแบบขั้นสุดท้าย

## 3. ระบบและเทคโนโลยี

- ใช้ Sanity เป็น CMS สำหรับจัดการผลงาน รูปภาพ ข้อความ รางวัล กิจกรรม และข้อมูลติดต่อ
- ใช้ Next.js หรือ frontend framework ที่เหมาะสมกับ Sanity
- รองรับ desktop, tablet และ mobile
- มี accessibility และ SEO metadata เบื้องต้น
- Inquiry form ส่งข้อมูลผ่านอีเมลหรือ form service พื้นฐานตามวิธีที่ตกลงก่อนพัฒนา
- จัดเก็บ source code ใน GitHub และ deploy บน hosting ที่เหมาะสม

## 4. สิ่งที่ส่งมอบ

- เว็บไซต์ production พร้อม public URL
- Source code และ GitHub repository
- Sanity CMS พร้อม content schema และเนื้อหาเริ่มต้นตามขอบเขต
- ระบบกรองผลงาน Project detail และ Inquiry form
- คู่มือใช้งาน CMS แบบสั้น
- Workshop การใช้งาน CMS 1 ชั่วโมง
- README หรือ deployment notes

## 5. ระยะเวลาดำเนินงาน

ระยะเวลา 1 เดือน เริ่มนับเมื่อได้รับเงินมัดจำ design reference และเนื้อหาที่จำเป็นครบถ้วน

| สัปดาห์ | งานหลัก |
| --- | --- |
| 1 | ยืนยันโครงสร้าง เนื้อหา design reference และ Sanity content model |
| 2 | ปรับงานออกแบบและตั้งค่า CMS |
| 3 | พัฒนา frontend เชื่อม CMS และปรับตาม feedback |
| 4 | QA แก้ไขรอบสุดท้าย deploy ส่งมอบ และจัด workshop |

หากผู้ว่าจ้างส่งเนื้อหาหรือ feedback ล่าช้า กำหนดส่งจะเลื่อนตามระยะเวลาที่ได้รับผลกระทบ

## 6. หน้าที่ของผู้ว่าจ้าง

ผู้ว่าจ้างต้องส่งและยืนยันข้อมูลต่อไปนี้:

- Design reference หรือ moodboard
- รายชื่อผลงาน ภาพถ่าย และรายละเอียดโครงการ
- ข้อความภาษาอังกฤษ รางวัล press references และข้อมูลติดต่อ
- สิทธิ์ในการใช้และเผยแพร่ภาพหรือเอกสารทั้งหมด
- Feedback แบบรวบยอดและการอนุมัติตามเวลาที่ตกลง

## 7. การแก้ไขและการควบคุมขอบเขต

ค่าบริการรวมการแก้ไข 2 รอบ โดยแต่ละรอบต้องเป็น feedback แบบรวบยอด การเปลี่ยนทิศทางหลังอนุมัติงานออกแบบ งานเพิ่มเติม หรือการเพิ่มเนื้อหาเกินขอบเขต จะประเมินราคาและระยะเวลาเพิ่มก่อนดำเนินการ

## 8. เกณฑ์การตรวจรับ

งานถือว่าส่งมอบครบเมื่อ:

- เว็บไซต์เปิดใช้งานผ่าน public URL ได้
- ส่วนประกอบตามขอบเขตทำงานบน desktop และ mobile
- เนื้อหาหลักดึงจาก Sanity CMS ได้
- Inquiry form ส่งข้อมูลได้ตามวิธีที่ตกลง
- ผู้ว่าจ้างสามารถแก้ไขเนื้อหาหลักผ่าน CMS หลัง workshop
- คุณเต้งอนุมัติงานออกแบบขั้นสุดท้าย
- ส่งมอบ source code คู่มือ และ deployment notes ครบถ้วน

## 9. ค่าบริการและการชำระเงิน

ค่าบริการรวมทั้งโครงการ **45,000 บาท** แบ่งชำระดังนี้:

1. 50% จำนวน 22,500 บาท เมื่อเริ่มโครงการ
2. 30% จำนวน 13,500 บาท หลังอนุมัติงานออกแบบและโครงสร้าง CMS
3. 20% จำนวน 9,000 บาท ก่อนเปิดเว็บไซต์และส่งมอบ

ค่าบริการนี้ไม่รวมค่า domain, hosting, Sanity paid plan, form service หรือบริการภายนอกอื่น โดยผู้ว่าจ้างเป็นผู้ชำระตามจริง การหักภาษี ณ ที่จ่ายให้เป็นไปตามกฎหมาย

## 10. งานที่ไม่รวมในขอบเขต

- เว็บไซต์สองภาษาเต็มรูปแบบ
- หน้าย่อยหรือผลงานเกินจำนวนที่กำหนด
- Copywriting หรือการแปลเนื้อหาทั้งหมด
- ระบบสมาชิก ชำระเงิน booking CRM หรือ backend เฉพาะทาง
- การเผยแพร่ drawings หรือแบบก่อสร้างครบชุด
- งานดูแลและอัปเดตเว็บไซต์ต่อเนื่องหลังส่งมอบ
