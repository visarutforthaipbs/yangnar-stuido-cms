# Pham workshops & activities

In Sanity, choose **Pham workshops & activities → Create**. Each document is one activity; multiple documents appear on `/pham`, newest date first.

- **Event:** title, slug, start date, optional end date, time in Thailand, venue, map URL, summary, registration status and hide switch.
- **Details & registration:** rich text for the story, programme, meals, overnight arrangements and registration instructions. Supports paragraphs, headings, lists and links. Separate fields hold fee in THB, discount text, minimum age, capacity, registration form URL and contact telephone.
- **Images:** one required cover/poster and up to two additional images (three total). Include image descriptions; optional captions are supported for additional images. Posters keep their original proportions.

Publish when ready. The website refreshes CMS content through its normal cache cycle. Only Open activities show a registration button. End dates (or start dates for single-day events) before today in Thailand display as Past event automatically, even if the editor left registration Open. Full and Closed statuses remain visible without a registration button.

The latest visible event by start date is highlighted automatically. All other visible events appear in a newest-first archive; click a row to expand its complete details and images. Adding another activity in Sanity does not replace existing activities. Use Hide from website for withdrawn examples.
