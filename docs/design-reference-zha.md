# Yangnar visual direction — ZHA reference

Reference: https://www.zha.com/ — inspected 16 September 2026.

Observed: black page canvas; large, regular-weight sans-serif headlines; full-viewport architectural media with white overlaid text; compact uppercase navigation; restrained borders; generous section spacing; image-led news and expertise modules; numbered carousel content.

Application to Yangnar: full-screen project photography, manual featured-project controls, black/white typography, two-column project archive, wide Pham image section, simple numbered practice modules, and responsive mobile navigation. All imagery and content come from Yangnar's existing CMS. No ZHA branding, photography, video, or source code is reused.

The hero uses still images because Yangnar has no supplied showreel. Controls are manual to avoid unsolicited motion. The native project dialog traps keyboard focus and supports Escape. The inquiry form remains the existing local summary prototype; it does not send inquiries.
