# Yangnar Studio — single-page website

Public site: <https://visarutforthaipbs.github.io/yangna-demo/>

Open `index.html` directly in a modern browser. No build, packages, server, or internet connection is required for the page itself; external links need internet access. All styles, scripts, project data, and images are embedded.

Every push to `main` deploys the site through GitHub Pages using the workflow in `.github/workflows/pages.yml`.

Includes the six-project filterable archive, accessible native project dialogs, studio philosophy, founders and delivery workflow, Pham feature, recognition, studio contacts, and a validated inquiry simulation. Submissions are displayed in the browser only and are not transmitted or persisted.

Project data follows the supplied PRD. Images were extracted from the existing Yangnar Studio company profile PDF in `demo-yangna`; the original source files and existing mockups remain available. The studio mark is a concept for this mockup. System serif and sans-serif fonts keep the prototype fully offline.

Verified with Chromium at desktop (1440 px), tablet (820 px), and mobile (390 px): category counts, all case-study dialogs, Escape and backdrop dismissal, inquiry confirmation and reset, mobile navigation, image loading, and horizontal overflow.
